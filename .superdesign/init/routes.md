# Routes — hosted hash SPA

File: `site/index.html` at `https://staging-portal.halcyonlabs.uk`

| Hash | Title | Renders |
| --- | --- | --- |
| `#/` or `#/workspace` | Workspace | Crew roster + chat room |
| `#/insights` | Insights | KPI cards, 14-day chart, insight list |
| `#/insight/:id` | Insight detail | Single insight |
| `#/admin` | Access | Grant sandboxes (allowlisted admins) |
| (signed out) | Login | Centered login |

Local Next.js `apps/portal` is not the hosted product.
